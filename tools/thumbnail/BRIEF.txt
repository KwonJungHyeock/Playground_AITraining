■ 에듀이노 코스 썸네일 제작 규격 (첨부 이미지와 동일 형식)

[0] 결과물
  - 500 x 500 px PNG, 그리고 2배수 1000 x 1000 px 각 1장
  - 장면(3D 렌더)만 코스마다 새로 만들고, 아래 글자/색/레이어 수치는 전부 그대로 쓴다
  - 아래 수치는 모두 500 x 500 기준. 1000px 로 만들 땐 전부 2배

[1] 서체 — Pretendard 한 종류만 사용
  - 패밀리 : Pretendard (v1.3.9)
  - 굵기   : ExtraBold(800), Bold(700) 두 가지만
  - 다운로드:
      https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/packages/pretendard/dist/web/static/woff2/Pretendard-ExtraBold.woff2
      https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/packages/pretendard/dist/web/static/woff2/Pretendard-Bold.woff2
  - 웹 CSS :
      https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css

[2] 제목 (가장 큰 글씨, 왼쪽 아래)
  - 크기   : 38 px
  - 굵기   : ExtraBold (800)
  - 행간   : 1.2  (= 45.6 px)
  - 자간   : -0.035 em   (Figma 입력값 -1.33)
  - 색     : #FFFFFF
  - 그림자 : X 0 / Y 2 / Blur 18 / rgba(0,0,0,0.5)
  - 줄 수  : 2줄 고정. 한 줄 11자 넘으면 36 px 로만 내린다

[3] 카테고리 (제목 바로 위 작은 줄)
  - 크기   : 13 px
  - 굵기   : ExtraBold (800)
  - 자간   : +0.14 em   (Figma 입력값 1.82)
  - 앞부분 : #FF9A3F          예) VISION AI
  - 뒷부분 : rgba(255,255,255,0.62)   예)  · 이미지 분류
  - 제목과의 간격 : 아래 11 px
  - 형식   : [영문 대문자 카테고리] + " · " + [국문 세부주제]

[4] 글자 블록 위치
  - 왼쪽에서 30 px, 아래에서 30 px 지점에서 시작 (오른쪽 여백도 30 px)

[5] 콜아웃 말풍선 (번호 1, 2)
  - 말풍선
      높이        : 30 px
      안쪽 여백   : 왼쪽 7 px / 오른쪽 12 px
      모서리 둥글기: 9 px
      배경        : rgba(6,10,26,0.9)
      테두리      : 1 px / rgba(255,255,255,0.18)
      그림자      : X 0 / Y 6 / Blur 18 / rgba(0,0,0,0.45)
      번호원과 글자 간격 : 7 px
  - 번호 원
      지름 17 px / 배경 #FF9A3F / 숫자 11 px ExtraBold / 숫자색 #231200
  - 말풍선 글자
      12.5 px / Bold(700) / 자간 -0.01 em / #FFFFFF
  - 개수 : 최대 2개. 3개부터는 500px 에서 안 읽힌다

[6] 지시선과 지시점
  - 지시선 : 2 px, 색 #FFB168, 점선 패턴 3 / 5, 끝 둥글게, 불투명도 92%
  - 시작점 : 말풍선의 "왼쪽에서 16 px 지점, 아래쪽 모서리"
  - 지시점 : 지름 9 px 원, 색 #FFB168
  - 지시점 발광 : 0/0/Blur 0/Spread 5 rgba(255,154,63,0.26)
                 + 0/0/Blur 16/Spread 5 rgba(255,154,63,0.5)
  - ※ 지시점은 반드시 장면 속 "실제 대상" 위에 올린다. 허공을 가리키면 안 된다

[7] 사진 위에 까는 레이어 3겹 (아래에서 위 순서)
  1) 3D 렌더 사진 — 500x500 꽉 채움
  2) 네이비 틴트 — 전면 #0F142C, 불투명도 24%
  3) 비네트 — 원형 그라데이션
        중심 50% 34% / 크기 118% x 92%
        30% : 투명
        72% : rgba(15,20,44,0.62)
        100%: rgba(10,15,38,0.92)
  4) 하단 글자자리 — 아래쪽 270 px 높이, 위에서 아래로 세로 그라데이션
        0%  : 투명
        44% : rgba(10,15,38,0.74)
        72% : rgba(10,15,38,0.96)
        100%: #0A0F26

[8] 색 정리
  포인트(앰버)   #FF9A3F
  지시선/지시점  #FFB168
  바닥 네이비    #0A0F26
  틴트 네이비    #0F142C
  제목           #FFFFFF
  부제           rgba(255,255,255,0.62)

[9] 레이아웃 금지 구역  ※ 가장 많이 틀리는 부분
  - 좌상단 x 20~202 / y 20~58 : 비워 둘 것
      → 플랫폼 카드가 이 자리에 "이용권 미보유" 배지를 덮어쓴다.
         여기에 말풍선을 두면 실제 카드에서 통째로 가려진다
  - 위쪽 0~165 px : 카드가 어두운 그라데이션을 덮어쓰므로 중요한 요소 금지
  - 아래쪽 330~500 px : 글자 자리. 장면의 중요한 부분을 두지 말 것

[10] 첨부 이미지에 쓴 실제 값 (참고)
  카테고리  VISION AI · 이미지 분류
  제목      내 사진으로 배우는 / AI 분류기
  말풍선 1  "내가 모은 사진"  위치 (290, 34)   지시점 (252, 112)
  말풍선 2  "AI가 알아봐요"   위치 (262, 176)  지시점 (243, 246)

[11] 3D 렌더(밑그림) 조건
  - 밝은 나무 책상 / 약간 위에서 내려다본 3/4 각도 / 무광 3D 느낌
  - 포인트 색은 코랄 (#F0473A ~ #FF8A3D)
  - 글자, 숫자, 로고 일체 금지 (글자는 위 규격으로 따로 얹는다)
  - 코스마다 "대표 사물"이 하나씩 달라야 한다
      예) 피지컬 AI = 로봇팔 / 비전 = 카메라 / 음성 = 마이크 /
          데이터 = 표·그래프 / 텍스트 = 말풍선·문서 / 제스처 = 손
  - 렌더 원본 1024 x 1024 는 따로 보관한다
