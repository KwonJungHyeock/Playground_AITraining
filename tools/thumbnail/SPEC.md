## 2. 글자 규격

### 카테고리 (윗줄)

| 항목 | 값 |
| --- | --- |
| 크기 | **13 px** |
| 굵기 | ExtraBold (800) |
| 자간 | **+0.14 em** (Figma: `letter-spacing 1.82`) |
| 앞부분 색 | `#FF9A3F` — 예: `VISION AI` |
| 뒷부분 색 | `rgba(255,255,255,0.62)` — 예: ` · 이미지 분류` |
| 아래 여백 | 11 px |

형식은 `영문 대문자 카테고리` + ` · ` + `국문 세부주제`.

### 제목 (큰 글씨)

| 항목 | 값 |
| --- | --- |
| 크기 | **38 px** |
| 굵기 | ExtraBold (800) |
| 행간 | **1.2** (= 45.6 px) |
| 자간 | **−0.035 em** (Figma: `letter-spacing -1.33`) |
| 색 | `#FFFFFF` |
| 그림자 | `0 2 18 rgba(0,0,0,0.5)` |
| 줄 수 | **2줄 고정** |

> 한 줄 11자를 넘기면 38px 에서 넘친다. 넘칠 때만 36px 로 내린다.

### 블록 위치

좌측 **30 px**, 하단 **30 px** 에서 시작. 우측 여백도 30 px.

## 6. 레이아웃 금지선

- **위쪽 1/3(0–165 px)은 비워 둔다.** 카드가 거기에 어두운 스크림과
  `이용권 미보유` 배지를 얹는다. 콜아웃을 둘 거면 **y ≥ 36 px 이면서
  왼쪽 배지(대략 x 14–150, y 14–40)를 피할 것.**
- **아래 1/3(330–500 px)은 글자 자리.** 장면의 중요한 부분을 두지 않는다.
- 콜아웃은 **2개까지.** 3개부터 읽히지 않는다.

## 8. 밑그림(3D 렌더) 조건

코스마다 밑그림만 새로 만들고 위 규격은 그대로 쓴다.

- 밝은 **나무 책상** · 약간 **위에서 본 3/4 각도** · 무광 3D
- 코랄(`#F0473A`→`#FF8A3D`) 포인트
- **글자·숫자·로고 일체 금지** (글자는 이 규격으로 따로 얹는다)
- 코스마다 **대표 사물이 하나씩 달라야 한다**
  (피지컬 AI=로봇팔 · 비전=카메라 · 음성=마이크 · 데이터=표/그래프 …)
- 원본 1024×1024 를 `*-source-1024.png` 로 남긴다
