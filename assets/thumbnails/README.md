## ai-train-infer 제작 메모

Figma AI 이미지 생성(`gpt-image-2.5-flare`)으로 만든 3D 렌더.
직접 그린 벡터안(노트북 UI · 사진 더미 · 픽셀 격자)은 전부 폐기했다 —
작은 크기에서 "노트북 그림" 또는 "얼굴 인식"으로만 읽혀 주제가 전달되지 않았다.

장면: 카메라가 사물 셋(컵·공·책)을 보고, 각 사물에 코랄 인식 괄호가 떠 있고,
위쪽 유리 패널에 확신도 게이지가 돈다.

- Figma 작업 파일: `Eduino AI — 콘텐츠 썸네일` (팀: Eduino_컨텐츠사업팀)
- 1024 원본에서 `(38,62)–(1000,1024)` 정사각 크롭 후 축소
- 프롬프트 핵심: 밝은 스튜디오 배경 · 무광 3D · 코랄(#F0473A→#FF8A3D) 포인트 ·
  **글자/숫자/로고 일체 금지**
