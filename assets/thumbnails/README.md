# 콘텐츠 썸네일

500×500 · 카드 안에서 쓴다. 글자는 이미지에 직접 얹는다
(운영 중인 `로봇 캘리그래피` 카드와 같은 방식).

| 파일 | 내용 |
| --- | --- |
| `ai-train-infer.png` / `@2x` | **AI 학습·추론 — 확정안.** 사진을 모아 가르치는 장면 |
| `alt-sorting.png` | 대안 — 두 무리로 분류하는 장면 |
| `*-source-1024.png` | 글자 얹기 전 3D 렌더 원본 |

## 규칙

- 코스마다 **대표 사물이 하나씩 달라야** 한다. 카드 목록에서 제목을 읽기 전에
  그림부터 훑기 때문이다 (피지컬 AI=로봇팔, 비전=카메라, 음성=마이크 …)
- 장면 톤 통일: 밝은 나무 책상 · 약간 위에서 본 3/4 각도 · 코랄 포인트
- 썸네일 **위쪽 1/3 은 비워 둔다** — 카드가 거기에 어두운 스크림과
  `이용권 미보유` 배지를 얹는다
- "AI" 글자는 넣지 않는다. 코스 6개 중 5개 제목에 이미 들어 있어 구분에 보탬이 안 된다

제작 도구와 좌표 규칙은 `tools/thumbnail/README.md`.
